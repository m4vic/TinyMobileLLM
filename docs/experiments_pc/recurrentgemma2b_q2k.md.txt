### 6. Interpretation

#### Architecture Advantage

RecurrentGemma uses a state-space model (recurrent attention), which usually offers:

-faster inference
-linear scalability
-lower memory footprint

#### On your PC:

- Decode speed (26 tokens/s) is close to Gemma e2B Q3_K (~22 tokens/s)
- But with much lower memory usage (~2.0 GB vs ~2.7 GB)

#### Memory Efficiency

- 2.09 GB RAM usage is quite efficient for a 2B model
- Better suited for mobile testing than regular Gemma 2B

#### Performance Notes

- Decode time is somewhat slower due to Q2 quantization + sequence length
- Sampling speed is high (8791 tokens/s), showing efficient computation
- Load time (0.61s) is very good for a 2B recurrent model

### Quality Consideration

Q2_K quantization is aggressive → can affect output quality, but useful for device testing.

### 7. Notes

- RecurrentGemma is a promising model class for mobile experiments.
- Lower RAM usage than standard Gemma makes it much more mobile-friendly.
- This model will be interesting to test in Termux due to its recurrent design advantages.
