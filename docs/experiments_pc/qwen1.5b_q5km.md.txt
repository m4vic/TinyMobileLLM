### 6. Interpretation

RAM usage is identical to Q4_K_M (~1.63GB), meaning Q5 precision does not add extra memory overhead under K_M scheme.
Decode speed is ~33 tokens/s, essentially the same as Q4_K_M.
This means performance penalty from Q4 → Q5 is almost zero on CPU.
Higher precision mainly improves generation quality, especially factual accuracy and coherence.
Load time is still under half a second, which is impressive.

Conclusion:
This is the highest-quality quantization you tested for Qwen 1.5B, with almost no performance loss compared to Q4.

Still too large for most 6–8GB mobile devices.
